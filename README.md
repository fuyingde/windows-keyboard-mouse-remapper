# 键盘鼠标映射工具 v2.6

一款轻量、直观、实时生效的 Windows 键盘与鼠标辅助工具，提供键鼠映射、自动按键，以及独立或全局生效方式。

[简体中文](./README.md) · [English](./README.en.md)

> 最新正式版以 EXE 发布。打开即可使用，无需配置开发环境。

## 下载最新版

当前版本只发布可执行文件，不再随仓库公开 1.8 之后的全部源码。官网和 GitHub Releases 都提供同一份最新安装包：

- 官网下载：[https://www.imtr.cn/keymousetools](https://www.imtr.cn/keymousetools)
- GitHub 下载：[Releases](https://github.com/fuyingde/windows-keyboard-mouse-remapper/releases/latest)

下载 `KeyMouseTools-v2.6.exe` 后直接运行即可。首次启动时选择界面语言，即可开始添加映射或自动按键。

## 开源与后续计划

仓库中已经公开的源码停留在 **1.8**。1.8 之后的版本继续迭代功能，但目前只发布 EXE；是否再次开源，会在后续单独考虑。

你可以按自己的需要选择：

- 需要最新功能：下载官网或 GitHub 上的最新 EXE
- 希望继续查看或编译源码：使用仓库中已公开的 [1.8](https://github.com/fuyingde/windows-keyboard-mouse-remapper/releases/tag/v1.8)

1.8 仍可正常使用。它覆盖基础键鼠映射，但不包含 1.9 之后增加的自动按键激活方式、全局生效、预设导入导出等能力。

## 它能做什么

- 将键盘按键、鼠标按键或最多三个按键的组合映射为其他按键或组合
- 将映射目标设置为“无”，在软件运行期间临时屏蔽指定输入
- 创建自动按键任务，支持单击、双击、执行间隔、循环次数和随机按下时长
- 使用统一热键、独立热键或长按生效来控制自动按键任务
- 在独立生效或全局生效方式下管理映射和自动按键任务
- 通过顶部总开关临时停止全部接管，让按键立即恢复原本功能
- 使用虚拟键盘录入损坏或不方便按下的按键
- 支持托盘运行、开机自启、静默启动、窗口置顶、预设导入导出和中英文界面

它适合临时替代损坏或不顺手的按键、调整鼠标侧键、屏蔽容易误触的按键，以及把常用组合改成更省力的操作。映射只在软件运行期间有效，完全退出后会立即恢复原始输入。

## 使用方法

### 键鼠映射

1. 选择“键鼠映射”，点击“添加映射”
2. 依次录制映射前和映射后的按键或组合
3. 保存后勾选该条映射，使其开始生效

原始输入和映射目标均支持最多三个按键。将映射目标设为“无”并启用该条映射，可临时屏蔽原始输入；取消勾选后会立即恢复原有输入。

### 自动按键

1. 选择“自动按键”，点击“添加自动按键”
2. 录制要自动执行的按键或组合，并设置间隔、执行方式和循环次数
3. 保存并勾选任务，再使用当前激活方式的热键启动或停止任务

自动按键支持统一热键、独立热键和长按生效。强制停止键始终有效，可用于立即停止全部自动按键任务。

### 生效方式

“独立生效”是默认方式，切换功能时只有当前功能中已勾选的规则运行。

启用“全局生效”后，标记为“全局”的映射和自动按键任务可跨功能同时运行。软件会检查已知按键冲突，但复杂组合仍应先自行测试。

## 运行环境

- 64 位 Windows 10 或 Windows 11
- Microsoft Edge WebView2 Runtime，多数现代 Windows 已经安装
- 运行以管理员身份启动的软件时，本工具也需要以管理员身份运行

## 隐私与使用边界

- 软件不会主动联网，也不会收集或上传用户配置
- 关闭按钮默认可最小化到托盘，也可在基础设置中改为退出软件；通过托盘菜单选择“退出”才会在最小化到托盘时完全停止
- 本工具使用全局输入钩子和模拟输入。部分使用独占输入、反作弊或其他限制机制的软件可能无法响应
- 请遵守相关软件和服务的使用规则

少数安全软件可能对全局输入类工具产生误报。请从官网或本仓库 Releases 下载，并以 GitHub Release 自动生成的 SHA-256 为准。
