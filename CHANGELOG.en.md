# Changelog

## 2.6

- Fixed some logic bugs in Auto Press

## 2.5

- Added F13-F24 keys to the virtual keyboard, and mapping supports these keys.

## 2.4

- Added Silent start, so the app window is not shown at launch
- Improved Force Stop logic

## 2.3

- Added a virtual keyboard
- Improved Settings, About, and Help
- Improved Global activation selection rules
- Added English language support

## 2.2

- Added a per-row enable checkbox for Key Mapping. New mappings remain inactive until selected
- Added Independent and Global activation scopes with a risk confirmation before enabling Global scope
- In Global scope, the row checkbox becomes a single Global selection that runs across features
- Added real-time conflict checks for mapping sources, control hotkeys, and output keys across features
- Fixed source keys being swallowed after their mapping was unchecked
- Allowed wheel directions for Unified and Independent hotkeys with a 200 millisecond debounce

## 2.1

- Improved the master input switch and added a clear hotkey-release notice when it is off
- Added Always on Top and local script preset import and export
- Suspended other hotkeys during recording and canceled recording when the app loses focus, is minimized, or is hidden
- Fixed system menu behavior when recording Win, Alt, or Esc

## 2.0

- Added a master input switch for temporarily disabling all mappings, Auto Press tasks, and control hotkeys
- Added a random Auto Press duration range with a default of 5 to 10 milliseconds
- Improved Auto Press timing and immediate release behavior when stopped

## 1.9

- Added Independent Hotkeys for Auto Press tasks
- Added dedicated controls and task layouts for all three activation modes
- Added in-app Help

## 1.8

- Added switching between Key Mapping and Auto Press
- Added Auto Press tasks with up to three keys, individual intervals, single or double presses, and finite or unlimited repeats
- Added Unified Hotkeys and Hold to Run activation modes

## 1.7

- Added mapping combinations of up to three keys
- Added bidirectional prefix-conflict checks for source combinations
- Allowed multiple mappings to use the same key or combination as a target

## 1.6

- Improved mouse side-button mapping
- Fixed a blank interface caused by mouse side buttons

## 1.5

- Added Start with Windows and tray icon options
- Added background operation after closing, tray restoration, and single-instance activation

## 1.4

- Improved startup, tray, and single-instance behavior
- Changed Start with Windows to use the registry
- Set the startup registry value name to FuYing.KeyMouseTools

## 1.3

- Allowed copies of the app under one user account to share mappings

## 1.2

- Completed mapping save, load, and delete behavior
- Improved mapping edit states and feedback

## 1.1

- Improved key capture and mapping stability
- Improved the base interface and interactions

## 1.0

- Released the first Key Mapping version
- Added creation, saving, and execution of single-key mappings
