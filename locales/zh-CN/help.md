# 键鼠映射 {#mapping}

## 基本使用 {#mapping-basic}

键鼠映射用于把一个按键或组合键转换为另一个按键或组合键。

### 使用方法

1. 点击左侧的“添加映射”。
2. 依次录制映射前和映射后的按键，最多可以录制三个按键。
3. 确认显示内容正确后点击“保存”，再勾选映射前面的复选框使其生效。

> 把映射后的按键设置为“无”并勾选该映射，可以屏蔽映射前的按键；取消勾选后会立即恢复原键输入。

## 组合键规则 {#mapping-combo}

- 映射前和映射后均支持一至三个按键。
- Esc 可以作为映射前或映射后的普通按键使用。
- 最后一个映射前按键按下时立即触发，任意一个映射前按键松开后解除。
- 映射前的单键、双键和三键不能形成前缀冲突，例如 Ctrl 与 Ctrl+C 不能同时保存。
- 映射后的按键不检查重复或前缀冲突，多条映射可以指向同一个按键。
- 滚轮作为组合键时只能放在最后一位。

## 鼠标按键限制 {#mapping-mouse}

- 鼠标左键和右键不能单独映射，也不能位于组合键第一位。
- 先按下其他按键后，可以把鼠标左键或右键录制为组合键的第二位或第三位。
- 录制期间其他映射暂时停用，鼠标左键和右键在录制框外仍保持普通点击。
- 录制只在键鼠映射工具位于前台时有效。切换窗口、最小化或隐藏软件会结束录制：若已用虚拟键盘点过按键则提交，否则取消。

## 虚拟键盘 {#mapping-virtual}

- 点击标题栏“虚拟键盘”打开屏幕键盘，再点一次即可收起。
- 默认吸附在窗口底部；当前屏幕工作区高度不够时，会改为可拖动的悬浮键盘。
- 虚拟键只写入当前正在录制的映射框，不会向系统发送按键，也不会触发已保存的映射。
- 请先点击映射前或映射后的录制框再点虚拟键。未开始录制时点击，会提示先激活映射录入。
- 小键盘上方的“确定录入”平时不可用。用虚拟键盘点过按键后才可点击：1 或 2 个键后按“确定录入”完成单键或双键，满 3 键会自动完成。
- 实体键盘和虚拟键盘可以按按下或点击的顺序混录。点过虚拟键后，松开实体键不会立刻结束，需要确定录入、满 3 键，或点录制框以外的位置。
- 点空白处、切换窗口、最小化或隐藏软件时：如果已经用虚拟键盘点过按键，会提交已点按键；还没点过则取消本次录制。

# 软件设置 {#settings}

## 自启、托盘与语言 {#settings-general}

- 开启开机自启后，软件会在登录 Windows 时自动运行。
- 关闭窗口只会隐藏软件，已经勾选的映射会继续生效。
- 左键点击通知区域图标可以重新显示软件；右键菜单可以彻底退出。
- 隐藏托盘图标后，可以再次启动本软件恢复已有窗口。
- 切换界面语言会立即更新窗口标题、界面、提示和托盘菜单，不会停止映射。

## 映射总开关 {#settings-input}

- 关闭标题栏中的映射开关，会立即释放软件正在按住的按键并停用全部映射。
- 关闭后所有按键和鼠标按键恢复原本功能；重新打开后，已勾选的映射会再次生效。
- 这个开关只用于临时停用，每次启动软件时默认开启，不会保存上次关闭状态。

## 窗口置顶 {#settings-topmost}

- 点击最小化按钮左侧的置顶图标可以让窗口保持在其他普通窗口上方，再次点击即可取消。
