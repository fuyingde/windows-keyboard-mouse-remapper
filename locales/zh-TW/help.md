# 按鍵映射 {#mapping}

## 基本使用 {#mapping-basic}

按鍵映射可將一個按鍵或按鍵組合轉換成另一個按鍵或組合。

### 使用方法

1. 在左側選擇「新增映射」。
2. 依序錄製原始組合和目標組合，每組最多可包含三個按鍵。
3. 確認顯示的組合後選擇「儲存」，再勾選該映射即可啟用。

> 將目標設為「無」並啟用映射，可封鎖原始按鍵。取消勾選後，原始按鍵會立即恢復正常輸入。

## 組合規則 {#mapping-combo}

- 原始組合和目標組合都可包含一至三個按鍵。
- Esc 可作為一般的原始按鍵或目標按鍵。
- 按下最後一個原始按鍵時會立即觸發映射，放開任一原始按鍵時會釋放目標按鍵。
- 一鍵、二鍵及三鍵原始組合之間不能存在前綴衝突，例如 Ctrl 和 Ctrl+C 不能同時儲存。
- 目標組合不檢查重複或前綴，因此多條映射可以使用相同目標。
- 滾輪方向只能作為組合中的最後一個按鍵。

## 滑鼠按鍵限制 {#mapping-mouse}

- 滑鼠左鍵和右鍵不能單獨映射，也不能作為組合中的第一個按鍵。
- 先按下其他按鍵後，滑鼠左鍵或右鍵可錄製為第二或第三個按鍵。
- 錄製期間會暫停其他映射；滑鼠左鍵和右鍵仍可在目前錄製欄位以外正常點擊。
- 僅當鍵鼠映射工具位於前景時允許錄製。切換視窗、最小化或隱藏軟體會結束錄製：若已用虛擬鍵盤點過按鍵則提交，否則取消。

## 虛擬鍵盤 {#mapping-virtual}

- 標題列「使用說明」左側的「虛擬鍵盤」可開啟標準 104 鍵螢幕鍵盤，再按一次「收起鍵盤」即可關閉。
- 預設吸附在視窗底部；目前螢幕工作區高度不足時，會改為可拖曳的浮動鍵盤。
- 虛擬鍵只寫入目前正在錄製的對應欄位，不會向系統傳送按鍵，也不會觸發已儲存的對應。
- 請先點選原始或目標錄製欄位再點虛擬鍵。尚未開始錄製時點選，會提示先啟動對應錄入。
- 數字鍵盤上方的「確定錄入」平時無法使用。用虛擬鍵盤點過按鍵後才可點選：1 或 2 個鍵後按「確定錄入」完成單鍵或雙鍵，滿 3 鍵會自動完成。
- 實體鍵盤與虛擬鍵盤可依按下或點選的順序混錄。點過虛擬鍵後，放開實體鍵不會立刻結束，需要確定錄入、滿 3 鍵，或點錄製欄位以外的位置。
- 點空白處、切換視窗、最小化或隱藏軟體時：如果已經用虛擬鍵盤點過按鍵，會提交已點按鍵；還沒點過則取消本次錄製。

# 設定 {#settings}

## 開機自動啟動、系統匣和語言 {#settings-general}

- 開機自動啟動可在登入 Windows 後自動執行軟體。
- 關閉視窗後軟體會隱藏，已啟用的映射仍會繼續生效。
- 按一下通知區域圖示可重新顯示視窗，使用右鍵選單可完全結束軟體。
- 隱藏系統匣圖示後，再次啟動軟體即可還原原有視窗。
- 切換語言會立即更新視窗標題、介面、提示和系統匣選單，不會中斷映射。

## 映射總開關 {#settings-input}

- 關閉標題列的映射開關會立即釋放已按住的輸出，並停用所有映射。
- 關閉期間，所有鍵盤與滑鼠按鍵都會恢復原始功能；再次開啟後會重新啟用已勾選的映射。
- 此開關為暫時狀態，每次啟動軟體時預設為開啟。

## 視窗置頂 {#settings-topmost}

- 使用圖釘按鈕可讓視窗保持在一般視窗上方，再按一次即可取消。
