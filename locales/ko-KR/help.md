# 키 매핑 {#mapping}

## 기본 사용법 {#mapping-basic}

키 매핑은 키 또는 키 조합을 다른 키나 조합으로 바꿉니다.

### 사용 방법

1. 왼쪽에서 “매핑 추가”를 선택합니다.
2. 입력 조합과 출력 조합을 차례로 기록합니다. 각 조합에는 최대 3개의 키를 사용할 수 있습니다.
3. 표시된 조합을 확인하고 “저장”을 선택한 다음 해당 매핑의 확인란을 선택해 활성화합니다.

> 출력 대상을 “없음”으로 설정하고 매핑을 활성화하면 입력 키를 차단할 수 있습니다. 확인란을 해제하면 입력 키의 원래 기능이 즉시 복원됩니다.

## 조합 규칙 {#mapping-combo}

- 입력 및 출력 조합에는 1개부터 3개까지 키를 사용할 수 있습니다.
- Esc는 일반 입력 키나 출력 키로 사용할 수 있습니다.
- 마지막 입력 키를 누르면 매핑이 즉시 실행되고 입력 키 중 하나를 놓으면 출력 키도 해제됩니다.
- 1개, 2개, 3개 키로 된 입력 조합 사이에는 접두 충돌이 없어야 합니다. 예를 들어 Ctrl과 Ctrl+C는 함께 저장할 수 없습니다.
- 출력 조합은 중복이나 접두 관계를 검사하지 않으므로 여러 매핑에서 같은 출력을 사용할 수 있습니다.
- 휠 방향은 조합의 마지막 키로만 사용할 수 있습니다.

## 마우스 버튼 제한 {#mapping-mouse}

- 마우스 왼쪽 및 오른쪽 버튼은 단독으로 매핑하거나 조합의 첫 번째 키로 사용할 수 없습니다.
- 다른 키를 먼저 누르면 왼쪽 또는 오른쪽 버튼을 두 번째나 세 번째 키로 기록할 수 있습니다.
- 기록 중에는 다른 매핑이 일시 중지됩니다. 왼쪽 및 오른쪽 버튼은 활성 기록 입력란 밖에서 계속 정상적으로 클릭할 수 있습니다.
- 키·마우스 매핑 도구가 전면 창일 때만 기록할 수 있습니다. 창 전환, 최소화 또는 숨기기를 하면 기록이 즉시 취소됩니다.

# 설정 {#settings}

## 자동 시작, 알림 영역 및 언어 {#settings-general}

- Windows와 함께 시작을 켜면 로그인 후 프로그램이 자동으로 실행됩니다.
- 창을 닫으면 프로그램이 숨겨지고 활성화된 매핑은 계속 작동합니다.
- 알림 영역 아이콘을 왼쪽 클릭하면 창을 다시 표시할 수 있고, 오른쪽 클릭 메뉴에서 완전히 종료할 수 있습니다.
- 알림 영역 아이콘을 숨긴 경우 프로그램을 다시 실행하면 기존 창이 복원됩니다.
- 언어를 변경하면 매핑을 중단하지 않고 창 제목, 화면, 메시지 및 알림 영역 메뉴가 즉시 갱신됩니다.

## 전체 매핑 스위치 {#settings-input}

- 제목 표시줄의 매핑 스위치를 끄면 눌린 출력 키를 즉시 해제하고 모든 매핑을 비활성화합니다.
- 꺼져 있는 동안 모든 키보드 및 마우스 버튼은 원래 기능으로 돌아갑니다. 다시 켜면 선택된 매핑이 다시 활성화됩니다.
- 이 스위치는 임시 설정이며 프로그램을 실행할 때마다 켜진 상태로 시작합니다.

## 항상 위 {#settings-topmost}

- 핀 버튼을 사용하면 창을 일반 창보다 위에 유지할 수 있습니다. 다시 선택하면 해제됩니다.
